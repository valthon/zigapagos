zigapagos

Astro's islands. A native core. No Node.

Zigapagos is a static site generator that renders pages with a fast Zig binary and adds interactivity per-component with TSX islands — server-rendered at build time, hydrated in the browser only where you ask.

This button is a live island on this very page. View source: the rest of the page is plain HTML, and this is the only component that shipped JS.

Zigapagos is a fork of Loris Cro's SSG, extended with islands architecture. MIT licensed. Source on GitHub.
