# --- Needs a browser CI has never installed -----------------------------------------
# Both drive real Chromium via python3 + playwright. No workflow installs either, and
# `git grep playwright -- .github/ tests/` is empty. Adopting these means a
# `playwright install` step (~150MB) on top of the runtime cost below — and note the
# helpers launch with `channel="chrome"`, so it has to install Google Chrome, not
# Playwright's bundled chromium.
#
# WHERE THEY SHOULD EVENTUALLY RUN: not the PR path. A separate workflow on
# `schedule:` (nightly) plus `workflow_dispatch:`, with its own checkout, mise setup,
# `playwright install --with-deps chrome`, and the examples/tsx-site build — roughly
# 265s cold build + ~150MB browser install + ~245s of scripts, call it 9-10 minutes.
# Nightly is the right cadence because what they catch is a real-browser regression in
# hydration or runtime slicing, which arrives with a runtime/src change, not with an
# arbitrary PR — and because a browser job on every PR is the kind of cost that gets
# switched off six weeks later. workflow_dispatch is there so anyone touching
# runtime/src can run it on demand instead of waiting for the night.
