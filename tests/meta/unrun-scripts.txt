# Test scripts CI knowingly does not run, one per line: <path><space(s)><reason>.
#
# tests/meta/script-coverage.sh fails on a test script that is neither run by CI nor
# listed here, and on a row here for a script that IS run or no longer exists. The point
# is not to bless the gap — it is to make adding to it a deliberate, reviewed act. Two
# assertions in this repo were found rotted in one session purely because nothing ran
# the file; see that script's header.
#
# EVERY ROW IS A DEBT, NOT A DECISION THAT AGES WELL. A row should say what it would
# cost to run the script in CI, so the trade-off can be re-checked rather than
# re-litigated from scratch.
#
# MEASURED 2026-07-27, all 14 below verified PASSING by hand on Linux (zig 0.16.0,
# bun 1.2.23). Wall-clock is with a WARM examples/tsx-site build; the cold consumer
# build that has to precede them is ~265s on a CI runner (ci.yml's own measurement for
# an equivalent build). The 13 example scripts total ~369s warm, of which two Playwright
# scripts are 244s. So the honest cost of adding all of them to the PR path is a fresh
# ~5-minute consumer build plus ~6 minutes of scripts plus a browser install — see the
# placement note at the bottom.

site/test/build.sh                     Dogfood site build + prefix/branding assertions. 120s cold, 1.8s warm. pages.yml already builds site/ on every push to main, so a BUILD break is caught; what is unrun is only this script's five output assertions. Cheapest of the lot to adopt.

examples/tsx-site/test/parity.sh       2.2s. SSR/CSR golden parity over the dogfood pages.
examples/tsx-site/test/props_check.sh  3.5s. Asserts a clean site builds green under props-check=error.
examples/tsx-site/test/spa.sh          2.4s. SPA prerender + routing manifest + nginx/zigbase host config + code splitting. THIS is the script whose nginx assertions had rotted; fixed in this PR.

Drift here ships to consumers.

# --- Needs a browser CI has never installed -----------------------------------------
# Both drive real Chromium via python3 + playwright. No workflow installs either, and
# `git grep playwright -- .github/ tests/` is empty. Adopting these means a
# `playwright install chromium` step (~150MB) on top of the runtime cost below.
examples/tsx-site/test/hydrate.sh      124.6s, Playwright. Island hydration + interactivity + nested-slot adopt-hydration + npm-compat on ONE Preact. Same source-of-truth caveat as ssr.sh: init_from_astro.zig:845 ships a de-repo'd copy to generated projects.
examples/tsx-site/test/spa_slice.sh    119.6s, Playwright, and it `rm -rf .zig-cache zig-out` first — so it forces a FULL cold rebuild and destroys the warm cache for anything sequenced after it. Per-deployable runtime slicing: separation, size, fallback, one-Preact hydration.

# --- Recommended placement, if this debt is paid --------------------------------------
# Not `e2e-rest`. That job does NOT build the examples/tsx-site CONSUMER project (it
# builds the repo root), so adding these there buys a fresh ~265s cold build and would
# make e2e-rest the new critical path, past e2e-astro-importer's 11m33s.
#
# `e2e-dev-loop` already pays exactly that consumer build (it runs examples/tsx-site's
# own `zig build dev`, 5m42s) and is NOT the critical path. The eleven non-browser
# scripts above total ~48s warm, so appending them there is ~+1 minute on a job with
# ~6 minutes of headroom. That needs a ci.yml edit and belongs in a focused CI change,
# not in the PR that found the rot.
#
# The two Playwright scripts want a separate scheduled/workflow_dispatch job: they are
# ~4 minutes plus a browser install, and their failure mode (a real browser regression)
# does not need to gate every PR.
#
# The eight *_playwright.py helpers under examples/tsx-site/test/ that no .sh invokes at
# all (spa, spa_csp, spa_guards, spa_nested, spa_nested_guarded, spa_reload, spa_scroll,
# spa_split) are a related but distinct gap: they are documented as manually run, and
# they are NOT in this file because it inventories .sh test scripts. Worth its own pass.
